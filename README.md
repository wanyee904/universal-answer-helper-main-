# 万能答题助手（无障碍节点读取版）

不截图、不 OCR、不限定某个 App：通过**无障碍服务直接读取当前界面的文本节点**，
自动识别题目与选项，调用题库 / 联网搜索 / AI 求解，并**直接点击选项节点**完成作答。

## 功能

- 界面文本节点读取：识别快、文字 100% 准确
- 自动识别题型：选择题 / 判断题 / 大题，也可手动切换
- 答案来源：本地题库 → 联网搜索（选择题）→ AI（OpenAI 兼容接口，默认 DeepSeek）
- 自动点击：直接对选项控件执行点击（比坐标更可靠），失败时按文字查找、坐标手势兜底
- 弹窗支持：题目/选项编辑、题型切换、翻译模式、答案标绿、收起为悬浮球
- 悬浮球可拖动，点球恢复弹窗

## 编译运行

1. Android Studio 打开本目录 `universal-answer-helper`
2. Sync + Run 安装到手机（Android 8.0+）

## 使用步骤

1. 打开应用：配置 AI 接口（可留空只走联网/题库），打开「自动模式」开关（可选）
2. 点「悬浮窗权限」允许；点「无障碍服务」开启本应用；「应用耗电管理」选择“完全允许后台行为”；后台锁定应用
3. 回应用点「开始答题」
4. 切换到任意答题页面（如 B 站硬核会员试炼、问卷、题库 App），悬浮窗会自动识别题目并显示推荐答案
5. 手动模式：点弹窗里的选项按钮即可自动点击屏幕对应选项；自动模式：高置信度答案自动点击（测试阶段，不稳定且耗token多）

## 翻译模式

弹窗点「翻译」→ 当前界面文本作为原文 → AI 中英互翻（保留排版），可点「编辑」修改原文重新翻译。

## 注意

- 本工具仅供学习 Android 无障碍技术使用；自动答题可能违反目标平台用户协议，风险自负
- 悬浮窗首次使用需授权「显示在其他应用上层」
- 编辑题目时选项数量全局生效（默认 4，2–26）
- 本工具处于测试阶段，对复杂题目识别仍存在问题
