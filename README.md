# 万能答题助手

基于 **Android 无障碍服务** 的答题辅助工具：直接读取界面文本节点（不截屏、不做 OCR 也能工作），
识别题目与选项，结合本地题库 / 联网搜索 / AI 求解，并直接点击选项完成作答。
另内置**整页翻译**、**应用内剪贴板**、**使用教程**与**启动动画**。

---

## 一、功能总览

### 1. 题目识别（无障碍节点读取）

| 能力 | 说明 |
|---|---|
| 文本节点直读 | 文字 100% 准确，不受分辨率/字体影响 |
| 多窗口扫描 | 优先当前聚焦窗口，其次遍历全部窗口（含弹窗、子窗口） |
| 标号兼容 | `A.` / `A、` / `A`+空格 / 裸字母 `A`，内容在同一或分离节点均可 |
| 无标号推断 | 题干以 ? ( ) （ ） 或下划线结尾时，后续连续短文本自动补 A/B/C/D |
| 完型填空 | 解析 `A) word  B) word` 词库 + 带编号空的文章，整篇一次求解 |
| 长文本 | 采集上限 4000 字符，长篇阅读/完型文章不丢 |
| 分节与噪声过滤 | 「一、单项选择题」「三、判断题」自动切换题型；跳过「此题已选择 0/4 项」、提交/保存等 |
| 题型过滤 | 只识别主页已开启的题型，其余跳过 |

### 2. 截屏 OCR 兜底

部分页面（自定义绘制、图片化文本、WebView 未暴露节点）读不到文字时，
用 **AccessibilityService.takeScreenshot + ML Kit（bundled 变体）** 做兜底识别，
模型打包在 APK 内，设备无需 Google Play 服务。

### 3. 答题引擎

优先级：**本地题库 -> 会话缓存 -> 联网 / AI**

- **联网 + AI 并行校验**（主页开关，默认开）
  - 一致：置信度取高者，来源标记「联网+AI」
  - 冲突：再问一次 AI 让它比较候选、选出最贴近题意的一项，并返回全部选项的接近度排序
- **联网优先**（关闭该开关）：先联网，搜不到才调用 AI，更省 token
- **单选题强制单选**：AI 若返回多个字母只取最接近的一个
- **接近度着色**：推荐=深绿，其余 黄绿 -> 琥珀 -> 橙 -> 红；AI 判定必错的选项不着色
- **重新解题**：跳过缓存与题库强制重算

### 4. 整页翻译

- 无障碍节点按坐标重排为「逻辑行 -> 段落」，不丢短文本、不截断整页
- 分批并发翻译（限流 + 结果缓存），失败块保留原文并在状态行提示
- 悬浮窗内双栏对照：**译文 / 原文** 各自可滚动，可切换查看

### 5. 剪贴板（应用内，与输入法剪贴板互通）

- 作为**题型按钮之一**并入功能区，点击展开已保存内容
- 每条与「单选题」按钮同高（32dp）、单行、超出省略
- **点条目即复制到输入法剪贴板**（会覆盖系统剪贴板，注意）
- 应用运行期间，用户复制的文字会**自动收集**进应用剪贴板（数量不限）
- 启动时若应用内已有内容与输入法剪贴板不同，**不做任何比对/清理**
- 主页「**管理剪贴板**」：查看 / 复制 / 编辑 / 删除 / 清空，页面顶部有风险提示

### 6. 编辑

- **随时可编辑**：识别不到题目也能进入编辑，手动输入或粘贴题目后直接求解
- 编辑框支持**全选 / 复制 / 粘贴**（应用内按钮 + 系统长按菜单）
- 可改题干、子问题、选项内容、选项数量（2-26）；选择题可切「单选题 / 多选题」

### 7. 悬浮窗与悬浮球

- 工具栏：识别 / 编辑 / 重新解题 / 收起 / 关闭
- 题型按钮只显示已开启的功能，等宽、数量多时横向滚动
- 收起后变成**可拖动悬浮球**（56dp 深色圆底 + 品牌绿描边 + 白色图标），点击恢复面板

### 8. 识别控制（功能处于测试阶段，暂不稳定）

| 设置 | 默认 | 说明 |
|---|---|---|
| 自动识别 | 关闭 | 界面变化后按冷却秒数节流识别（默认 5s，范围 2-120） |
| 手动识别 | - | 随时点「识别」立即强制识别 |
| 自动点击 | 关闭 | 高置信度答案自动点击选项 |

### 9. 启动动画

- 图标淡入 + 轻微放大（0-45%），随后电路走线从**尖端画向圆点**并点亮端点（30-100%），总时长 1 秒
- **跟随系统明暗**：浅色 = 白底黑标，深色 = 黑底白标

### 10. 界面

- Material 3 设计，浅色 / 深色双套配色
- 卡片式分区：AI 接口配置 / 功能自定义 / 识别与答题策略
- 自适应图标（Adaptive Icon），白色背景 + 前景图案

### 11. 使用教程

应用内「使用教程」分步引导：开启无障碍、允许完全后台行为（按 ColorOS / HyperOS / 其他机型分述）、
创建 DeepSeek API Key 及注意事项，并可直接跳转对应系统设置或网页。

## 三、编译

### Android Studio

1. 打开本目录 `universal-answer-helper`
2. Sync -> Run 安装到 Android 8.0+ 设备

### 命令行

```bash
./gradlew assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

> **JDK 说明**：项目要求 JDK 25 工具链。`gradle.properties` 已指向 Android Studio 自带的 JBR，
> 避免 Gradle 联网从 GitHub 下载 toolchain：
> ```properties
> org.gradle.java.installations.paths=C:/Program Files/Android/Android Studio/jbr
> ```

## 四、使用步骤

> 应用内点「**使用教程**」有分步引导并可跳转系统设置。

1. 打开应用，填写 AI 接口（OpenAI 兼容，例如 `https://api.deepseek.com/v1` + `deepseek-chat`），点「测试 AI 连接」
2. 在「功能自定义」只开启需要的题型（至少一项）
3. 授予「悬浮窗权限」-> 开启「无障碍服务」
4. 回应用点「开始答题」
5. 切到答题页面，悬浮窗显示题目与推荐答案；手动点选项即自动点击，或开启自动识别 + 自动点击

> 重装应用后无障碍授权失效，需要到设置里重新开关一次。
> MIUI / HyperOS 还需在开发者选项打开「USB 安装」才能用 Android Studio 安装。

## 五、配置项（SharedPreferences: `bili_helper`）

| 键 | 默认 | 含义 |
|---|---|---|
| `ai_base` / `ai_key` / `ai_model` | deepseek 默认 | AI 接口配置 |
| `web_ai_combo` | true | 联网 + AI 并行校验 |
| `auto_read` / `read_cooldown` | false / 5 | 自动识别与冷却秒数 |
| `auto_mode` | false | 自动点击 |
| `kind_choice` / `kind_judge` / `kind_essay` / `kind_cloze` / `kind_translate` | true | 各题型开关 |
| `kind_clipboard` | true | 剪贴板按钮显示 |
| `cloze_unique` | true | 完型选项唯一（不重复使用词） |
| `option_count` | 4 | 选择题选项数量（2-26） |
| `clip_items` | [] | 应用内剪贴板内容（JSON 数组） |
| `migrated_auto_off` | false | 一次性迁移标记（自动识别/点击默认关闭） |

## 六、隐私与限制

- **API Key 仅保存在本机**，不上传第三方
- 解题时**题目文本**会发送给你配置的 AI 接口，以及 Bing / DuckDuckGo 搜索
- 无任何统计、广告、崩溃上报 SDK，不采集设备信息
- **剪贴板会读写系统剪贴板**：复制条目会覆盖输入法剪贴板；应用运行期间复制的文字会被收集
- Android 10+ 对后台读取剪贴板有限制，自动收集为尽力而为，个别场景可能收不到
- WebView / 自绘页面依赖节点暴露程度，读不到时走截屏 OCR 兜底
- 完型填空的下拉选项点击依赖节点可点击性，必要时手动展开

## 七、常见问题

| 现象 | 处理 |
|---|---|
| 识别不到题目 | 主页确认对应题型已开启；用「识别」手动触发；必要时「编辑」手动输入 |
| 无障碍开启后无效 | 关掉再打开一次服务；确认没有被系统权限监控拦截 |
| Android Studio 装不上 | 卸载旧包再装（签名不一致会报 `INSTALL_FAILED_UPDATE_INCOMPATIBLE`） |
| 构建报下载 toolchain 失败 | 确认 `gradle.properties` 里的 JDK 路径存在 |
| 剪贴板收不到后台复制内容 | 系统限制所致，可先打开应用或展开剪贴板再复制 |
