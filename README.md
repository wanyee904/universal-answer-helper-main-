# 万能答题助手

通过 **Android 无障碍服务直接读取界面文本节点**（不截图、不做 OCR）识别题目与选项，
结合本地题库 / 联网搜索 / AI 求解答案，并**直接点击选项控件**完成作答。

适用于任意 App 的答题页面：学习通章节测验、问卷表单、题库类 App 等。

---

## 核心特性

### 一、题目识别（无障碍节点读取）

| 能力 | 说明 |
|---|---|
| 文本节点直读 | 速度快、文字 100% 准确，不受分辨率/字体影响 |
| 多窗口扫描 | 优先读取当前聚焦窗口，其次遍历所有窗口（含弹窗、子窗口） |
| 标号分离 | 支持 `A、` + 内容分成两个节点、`A.` 与内容同节点、`A` + 空格 + 内容、裸字母 `A` 等格式 |
| 无标号推断 | 题干以「？」/「( )」/「（ ）」/ 下划线结尾时，后续连续短文本自动补 A/B/C/D |
| 完型填空 | 解析 `A) word  B) word` 词库 + 带编号空的文章，一题搞定全篇 |
| 长文本 | 采集上限 4000 字符，长阅读、完型文章不会丢失 |
| 分节识别 | 「一、单项选择题」「三、判断题」自动切换题型；跳过 `此题已选择 0/4 项`、提交/保存等噪声 |
| 题型过滤 | 只识别主页已开启的题型，其余直接跳过 |

### 二、答题引擎

答案优先级：**本地题库 → 会话缓存 → 联网 / AI**

- **联网 + AI 并行校验**（主页开关，默认开）
  - 两边结果一致：置信度取高者，来源标记「联网+AI」
  - 两边冲突：自动再问一次 AI，让它比较候选、选出与题意最接近的一项，并返回全部选项的接近度排序
- **联网优先模式**（关闭该开关）：先联网搜索，搜不到才调用 AI，更省 token

### 三、答案展示

- **单选题强制单选**：AI 若返回多个字母，只取最接近的一个
- **接近度着色**：推荐答案深绿，其余选项按接近度 黄绿 → 琥珀 → 橙 → 红
- **必错选项不着色**（由 AI 的 wrong 列表判定）
- 多选题：所有正确项统一标绿

### 四、悬浮窗交互

- 工具栏：识别 / 编辑 / 重新解题 / 收起 / 关闭
- 题型按钮：只显示已开启的功能，按钮等宽，数量多时横向滚动
- 选择题可切换「单选题 / 多选题」
- 「重新解题」跳过缓存与题库，强制重新搜索
- 编辑模式：题干、子问题、选项内容、选项数量（2–26）均可改
- 收起为可拖动悬浮球，点击恢复

### 五、识别控制

- **自动识别**（默认关闭）：界面变化后按「冷却秒数」（默认 5s，2–120）节流识别
- **手动识别**：随时点「识别」，立即强制识别，不受冷却与开关限制
- **自动点击**（默认关闭）：高置信度答案自动点击选项

## 使用步骤

> 应用内点「**使用教程**」有分步引导（无障碍授权 / 后台保活 / DeepSeek API 创建），并可直接跳转对应系统设置页。

1. 安装后打开应用，填写 AI 接口（OpenAI 兼容，如 `https://open.bigmodel.cn/api/paas/v4` + `glm-4-flash`），点「**测试 AI 连接**」确认可用
2. 在「功能自定义」里只开启需要的题型（至少一项）
3. 点「悬浮窗权限」→ 允许「显示在其他应用上层」
4. 点「无障碍服务」→ 找到「万能答题助手」→ 开启
5. 回到应用点「**开始答题**」
6. 切换到答题页面，悬浮窗会显示题干、选项与推荐答案
   - 手动：点选项按钮，自动点击屏幕对应选项
   - 自动：开启「自动识别」+「自动点击」后会自行作答

> **重装应用后**无障碍授权会失效，需要到设置里重新开关一次服务。
> MIUI / HyperOS 还需在开发者选项里打开「USB 安装」才能通过 Android Studio 安装。

## 隐私说明

- **API Key 只保存在手机本地**（SharedPreferences），不上传到任何第三方
- 解题时**题目文本**会发送给你配置的 AI 接口，以及 Bing / DuckDuckGo 搜索
- 应用**不含**任何统计、广告、崩溃上报 SDK，不采集设备信息
- 不填写 Key 时只走本地题库与联网搜索，**不消耗任何 token**
- 每道题一次 AI 调用（联网+AI 模式下），失败会重试一次仲裁调用

---

## 已知限制

- 网页/WebView 页面依赖其无障碍节点暴露程度，个别页面可能读不到文字
- 完型填空的下拉选项点击依赖节点可点击性，必要时需手动展开
- 识别质量受页面结构与 AI 模型能力影响，答案仅供参考
